# PRD — 매매일지 (Trade History)

## 1. 배경과 목표
미국 주식 스캘핑(하루 약 5회 왕복) 매매를 **모바일에서 빠르게 기록**하고, 쌓인 기록으로 **내 매매 스타일·장단점·개선점**을 찾아 다음 매매에 반영한다.

| 목표 | 성공 기준 |
|---|---|
| 기록 부담 최소화 | 한 건 직접 입력 60초 이내, 캡처 업로드 시 체결 정보 자동 입력 |
| 복기 품질 | 모든 매매에 체결 전후 30분 1분봉 + 거래량 + 매수/매도 위치 표시 |
| 스타일 파악 | 시간대·셋업·보유시간·순번·감정별 성과, 규칙 기반 장단점 자동 진단 |
| 개선 루프 | 매주 AI 코치 리포트 + "다음 주 집중할 한 가지"를 홈에 고정 노출 |

## 2. 사용자·환경
- 사용자: 본인 1인 (토스증권, 미국 주식, 롱 온리, 분할 매수·매도 있음, 공매도 없음)
- 기기: 모바일 우선 PWA (홈 화면 설치), PC 브라우저 겸용
- 시간: 체결 입력은 한국시간(KST), 분석의 거래일·시간대 구분은 미국 동부시간(ET)

## 3. 기능 요구사항 (MVP)

### F1. 매매 기록
- 한 화면 입력: 티커, 체결 목록(매수/매도·시각(분)·가격·수량·수수료), 계획 손절가/목표가, 셋업 태그, 매수·매도 사유, 감정 태그, 확신도(1~5), 계획 준수 여부, 메모
- 하나의 포지션 = 보유수량 0 → 진입 → 0 으로 청산. 분할 체결은 평균단가 방식으로 손익 계산
- 수수료 미입력 시 설정의 수수료율(기본 0.1%) 자동 적용
- 입력 중 예상 순손익·수익률·R 배수 미리보기
- 수정·삭제

### F2. 캡처 자동 입력
- **기본(비용 없음)**: 앱에서 요청문 복사 → Claude 앱(구독)에 캡처와 함께 전송 → 답변(JSON)을 앱에 붙여넣기 → 자동 채움
- **선택(API 키 설정 시)**: 앱에서 바로 캡처 업로드 → 자동 분석
- 토스증권 체결내역 스크린샷 1~5장 업로드 → AI 가 체결 추출 → 종목별 포지션으로 자동 분리
- 1개 포지션: 폼에 채움 / 여러 개: 목록으로 보여주고 "모두 저장(사유는 나중에)" 또는 건별 편집
- 사유가 비어 있는 매매는 홈과 목록에서 "사유 미작성" 알림

### F3. 분봉 차트
- 첫 체결 30분 전 ~ 마지막 체결 30분 후 1분봉 + 거래량
- 매수(빨강 ▲)/매도(파랑 ▼) 마커, 평단·손절·목표 가격선, KST/ET 전환
- 저장 시 분봉을 받아 DB 에 캐시 (무료 API 보관 기간 제한 대응), 실패 시 재시도 버튼

### F4. 분봉 기반 매매 품질 지표
- MAE(보유 중 최대 역행), MFE(최대 순행), 매도 후 30분 최고가(조기 익절), 진입 전 10분 변화(추격매수), 수익 포착률

### F5. 통계·스타일 분석
- 기간: 이번 주 / 이번 달 / 3개월 / 전체
- 요약: 승률, 손익비, Profit Factor, 기대값, 평균 R, 최대 낙폭, 연승·연패, 이익/손실 평균 보유시간
- 분해: ET 시간대, 셋업, 보유시간, 하루 중 순번, 직전 매매 결과(복수매매), 감정, 계획 준수, 확신도, 요일, 종목
- 장단점 진단(규칙 기반): 손익비, 손실 버티기, 큰 손실, 강·약 시간대/셋업, 과매매, 복수매매, 감정, 계획 이탈 비용, 조기 익절, 이익→손실 전환, 추격매수

### F6. AI 주간 리포트
- **기본(비용 없음)**: 주 선택 → 요청문(통계+매매 요약+코치 지시) 복사 → Claude 앱(구독)에 붙여넣기 → 답변을 앱에 붙여넣어 저장
- **선택(API 키 설정 시)**: 매주 토요일 10:00 KST 자동 생성(지난주, 없을 때만) + 버튼 생성
- 입력: 주간 통계·분해·규칙 진단·매매별 요약(사유·MAE/MFE 포함)·직전 4주 요약·지난 과제
- 출력: 한 줄 요약, 숫자, 잘한 점, 반복된 실수, 사유 vs 결과, 지난 과제 점검, 다음 주 규칙 + "집중할 한 가지"

### F7. 홈 대시보드
- 오늘 / 이전 거래일 손익 (ET 거래일 기준)
- 일 손실 한도·일 매매 횟수 게이지 (설정값 도달 시 경고) — 스캘퍼 과매매 방지
- 사유 미작성 알림, AI 리포트의 "집중할 한 가지"
- 월간 손익 달력(평일) + 월 손익, 월 KPI(매매 수·승률·손익비·PF·평균 보유)
- 최근 30거래일 누적 손익 곡선

### F8. 설정·내보내기
- 입력/표시 시간대, 수수료율, 일 손실 한도, 일 최대 매매 수, 셋업·감정 태그 목록
- 내보내기: 포지션 CSV, 체결 CSV (엑셀 한글 호환), 전체 JSON 백업

## 4. 이후 단계 후보 (Phase 2+)
- 장전 계획/장후 복기 일일 저널, 나만의 규칙 체크리스트와 위반 추적
- 스크린샷(호가창·차트) 첨부 보관
- 토스증권 체결내역 CSV 가져오기(제공 시), 유료 실시간 데이터
- 원화 환산 손익, 세금 추정
- 월간 AI 리포트, 리포트 기반 규칙 자동 제안
