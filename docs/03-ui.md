# UI 설계

## 원칙
- 모바일 우선 (최대 폭 576px), 다크 모드 기본
- 국내식 색상: **이익·매수 = 빨강 `#f04452`, 손실·매도 = 파랑 `#3182f6`** (다크 배경 기준 색각 이상 검증 통과). 숫자에는 항상 +/− 부호를 붙여 색만으로 구분하지 않음
- 하단 탭 5개: 홈 · 매매 · (＋)기록 · 분석 · 리포트. 설정은 홈 우상단

## 화면
### 홈 `/`
1. 오늘 / 이전 거래일 손익 (건수·승패)
2. 오늘의 가드: 일 손실 한도 게이지, 매매 횟수 게이지, 한도 도달 경고
3. 사유 미작성 N건 → 작성 화면으로
4. AI 코치의 "이번 주 집중할 한 가지"
5. 월간 손익 달력(월~금, 손익 크기만큼 색 농도, 날짜 탭 → 그날 매매) + 월 손익 + 월 KPI
6. 최근 30거래일 누적 손익 곡선

### 기록 `/trades/new` (한 화면)
캡처로 채우기 → 티커 → 체결 행(매수/매도 토글·시각·날짜 / 가격·수량·수수료) → 손익 미리보기 → 손절·목표 → 셋업 칩 → 매수 사유 → 매도 사유 → 감정 칩 → 확신도·계획 준수 → 메모 → 저장(하단 고정)

### 매매 목록 `/trades`
ET 거래일별 그룹, 일 합계, 종목·시각·보유시간·태그·손익·R, 사유 미작성 배지. 티커 검색·기간 필터

### 매매 상세 `/trades/:id`
손익·수익률 → 핵심 지표 6칸 → 1분봉 차트(±30분, 마커, 가격선, KST/ET) → 분봉 기반 지표 → 체결표 → 태그·사유 → 수정/분봉 새로고침/삭제

### 분석 `/analysis`
기간 탭 → 요약 지표 12칸 → 누적 손익 → 장단점 진단(강점/개선 배지) → 분봉 기반 진단 → 분해 분석 10종 (0 기준 좌우 막대 + 건수·승률·합계)

### 리포트 `/reports`, `/reports/:id`
생성(주 선택) → 목록(주간 손익·focus) → 상세(집중할 한 가지 강조 + 본문)

### 설정 `/settings`
시간대, 수수료율, 한도, 태그 목록, 내보내기 3종, 연결 상태, 로그아웃
